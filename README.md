# Capo for Neos (`neos-capo`)

---

Based upon: <br>
[rviscomi/capo.js](https://github.com/rviscomi/capo.js) | [rviscomi/capo-wp](https://github.com/rviscomi/capo-wp)

---

Reorders the `<head>` of your word press pages for a faster FCP and better web performance.

All you need to do is simply require this package in your Neos project.

Default Configuration:
```yaml
Capo:
  options:
    debug: false
    debug_comment: false
    display_warnings: true
    display_weights: false
```
